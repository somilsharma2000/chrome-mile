# Vehicle Partnership Checklist

> **STATUS: CONCEPT STAGE.** No vehicle is secured, no placement is measured, no auction is
> live, and no price on this site is a commitment. This checklist is the gate: nothing may be
> described as confirmed, sold, or live until every item below is completed and recorded in the
> admin console (`/admin`).

Before any placement on Chrome Mile is offered for sale, every item in this checklist must be
complete, with evidence:

## 1. Vehicle access
- [ ] Target machine identified — a chrome cafe-racer in the character of a Royal Enfield Continental GT 650
- [ ] Owner identified and in conversation
- [ ] Physical access schedule agreed: storage, riding season, handover windows

## 2. Owner consent
- [ ] Written vehicle-owner agreement drafted (usage rights, duration, indemnities)
- [ ] Agreement signed by the owner
- [ ] Insurer notified of decal placement

## 3. Photographs
- [ ] Verified photographs of the actual machine captured per the photography checklist
- [ ] Concept imagery replaced by verified photographs (`lib/concept.ts`)
- [ ] Illustrative labels removed where no longer true

## 4. Measurement & templates
- [ ] Every placement physically measured on the actual machine
- [ ] Measured overlay templates replace illustrative hotspot coordinates
- [ ] Sizes in the placement specification updated from measurement, not specification sheets

## 5. Installation conditions
- [ ] Material compatibility confirmed (vinyl on painted chrome)
- [ ] Safety rules fixed: nothing on the number plate, lights, mirrors or controls
- [ ] Installer and install photography scheduled

## 6. Approvals
- [ ] Artwork approval flow live — mockup sign-off per placement before anything is printed
- [ ] Local/regulatory position on advertising on a private vehicle reviewed
- [ ] Payment provider approval for the auction hold/capture model, **if** an auction is run
      (no bidding goes live without provider approval in writing)

## 7. Duration & terms
- [ ] Campaign season duration fixed
- [ ] Deliverables schedule finalised: install photography, GPS-verified ride certificates, archive
- [ ] Real enquiry intake channel configured (the brand-interest form currently composes a
      message to a placeholder number)

## 8. Commercial terms
- [ ] Pricing decided and published (replacing the "pricing on partnership confirmation" note)
- [ ] Auction mechanics published — deposits, soft close, payment schedule, void and refund —
      only if an auction is actually run
- [ ] Sponsor agreement finalised beyond draft

## Inventory status rule

Every placement starts as **proposed**. A placement may be marked **reserved** only against a
signed note of interest, and **sold** only against a signed agreement. The public site's claims
must always match the admin console — no exceptions, no projections.
